# Key Tip

Плагин Obsidian показывает назначенные горячие клавиши в модальном окне поверх
интерфейса на компактной экранной клавиатуре формата 80%.

## Использование

1. Включите плагин `Key Tip` в `Settings -> Community plugins`.
2. Нажмите иконку клавиатуры в ribbon или вызовите команду, чтобы открыть
   модальное окно поверх заметок:
   `Key Tip: Open keyboard hotkey hints`.
3. Наведите мышку на подсвеченную клавишу, чтобы увидеть назначенную команду.
4. Удерживайте `Ctrl`, `Shift` или `Alt`, либо нажмите соответствующую клавишу
   на экранной клавиатуре, чтобы открыть слой комбинаций.

Можно одновременно включать несколько модификаторов, например
`Ctrl + Shift` или `Ctrl + Alt + Shift`.
